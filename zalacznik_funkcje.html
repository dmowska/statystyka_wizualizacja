Załącznik: zestawienie funkcji

Zestawienie wszystkich funkcji R używanych w rozdziałach 1–19, uporządkowane według rozdziałów. Służy do szybkiego odnalezienia właściwego polecenia — gdy wiesz, co chcesz zrobić, ale nie pamiętasz, jak się ta funkcja nazywa.

Opisy są celowo krótkie. Szczegóły (wszystkie argumenty, wartości domyślne, przykłady) znajdziesz zawsze na stronie pomocy: ?nazwaFunkcji.

Funkcje wymagające wczytania pakietu oznaczono w nawiasie, np. (dplyr). Pozostałe są dostępne od razu po uruchomieniu R.

Rozdział 1 — Wprowadzenie

Funkcja Zastosowanie
install.packages("nazwa") instalacja pakietu (jednorazowo)
library(nazwa) wczytanie pakietu (w każdej sesji)
data("zbior", package = "pakiet") wczytanie zbioru danych dołączonego do pakietu
read.csv("sciezka") wczytanie danych z pliku csv
str(obiekt) struktura obiektu: typy zmiennych i liczba obserwacji
colSums(is.na(df)) liczba braków danych w każdej kolumnie

Funkcja Zastosowanie

read.csv("plik.csv") wczytanie pliku csv (separator przecinek)
read.csv2("plik.csv") wczytanie pliku csv w formacie polskim (średnik, przecinek dziesiętny)
read.table("plik.txt", sep = " ") wczytanie pliku tekstowego z dowolnym separatorem
readRDS("plik.rds") wczytanie pojedynczego obiektu zapisanego w formacie R
load("plik.rda") wczytanie zapisanego środowiska pracy
write.csv(obiekt, "plik.csv") zapis ramki danych do pliku tekstowego
saveRDS(obiekt, "plik.rds") zapis pojedynczego obiektu w formacie R
save(a, b, file = "plik.rda") zapis wybranych obiektów

Najczęściej używane — jedną stroną

Jeśli nie pamiętasz, od czego zacząć:

# 1. wczytanie i obejrzenie danych
dane <- read.csv("dane/pomiary_pol.csv")
str(dane); summary(dane); colSums(is.na(dane))

# 2. wybór i przekształcenie
library(dplyr)
wybrane <- dane |> filter(wojewodztwo == "wielkopolskie") |> select(tmax_9, annual_precip)

# 3. statystyki opisowe w grupach
dane |> group_by(prowincja) |> summarize(srednia = mean(annual_tavg, na.rm = TRUE), n = n())

# 4. wykres
library(ggplot2)
ggplot(dane, aes(x = prowincja, y = annual_tavg)) + geom_boxplot() + theme_bw()

# 5. sprawdzenie założeń
shapiro.test(dane$annual_tavg)
car::leveneTest(annual_tavg ~ factor(prowincja), data = dane)

# 6. test i odczytanie wyniku
wynik <- t.test(annual_tavg ~ prowincja, data = dwie_prowincje)
wynik                 # pełny wydruk
wynik$p.value         # sama wartość p
wynik$conf.int        # przedział ufności
